Infrastructure Tools & Diagnostics

Simple, open-source tools for infrastructure troubleshooting, cloud operations, and automation.

  • IP Information View the address and request details seen by the service.

    curl https://xdb.com.br/api/ip

  • CIDR Calculator Calculate IPv4 and IPv6 networks.

    curl 'https://xdb.com.br/api/cidr?cidr=192.168.10.25/24'

  • DNS Lookup Look up public DNS records and TTL values.

    curl 'https://xdb.com.br/api/dns?domain=example.com&record_type=A'

  • AWS IAM Policy Validator Validate identity policy syntax and structure.

    curl -X POST 'https://xdb.com.br/api/aws/iam-validate' -H 'Content-Type: text/plain' --data-binary @policy.json

  • AWS Terraform Plan Inspector Summarize planned AWS resource changes and flag selected risks.

    curl -X POST 'https://xdb.com.br/api/aws/terraform-plan-analyze' -H 'Content-Type: application/json' --data-binary @plan.json

  • OCI Terraform Plan Inspector Summarize planned OCI resource changes and flag deletions or replacements.

    curl -X POST 'https://xdb.com.br/api/oci/terraform-plan-analyze' -H 'Content-Type: application/json' --data-binary @plan.json

  • OCI IAM Policy Analyzer Review OCI policy statements for duplicates, broad access, and potential redundancy.

    curl -X POST 'https://xdb.com.br/api/oci/iam-policy-analyze' -H 'Content-Type: application/json' --data-binary @oci-policy.json
